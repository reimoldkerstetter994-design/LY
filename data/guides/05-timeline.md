# 2027 报考时间线与官方入口

以下为常规全国硕士招考节奏，具体日期以教育部和南农研招网当年通知为准。

| 节点 | 通常时间 | 你要做的事 |
| --- | --- | --- |
| 目录预通知 | 2026-07 | 已发布；资环学硕未见科目调整 |
| **正式目录 / 章程** | **2026-09** | 本系统「立即抓取」；核对学生代码、人数、857 书目是否变化 |
| 推免接收 | 2026-09 起 | 学硕名额含推免，统考真实空额要等拟录取公示后估计 |
| 网上预报名 | 约 10 月上旬 | 中国研招网 yz.chsi.com.cn |
| 正式报名 | 约 10 月中下旬 | 学硕选 090301 或 090302，院系 003 |
| 网上确认 | 11 月 | 按报考点要求 |
| 初试 | 约 12 月下旬 | 政治、英语一、数学农或化学农、857 |
| 国家线 | 次年 2–3 月 | 农学门类 |
| 学院复试线与细则 | 次年 3 月 | 以下载的学院 PDF 为准，不要只看国家线 |
| 复试 | 近年在 3 月底，滨江校区线下 | 笔试 3 小时 + 面试 |
| 拟录取公示 | 4 月 | 学院网 + 学校研招网 |

## 本系统抓什么、不抓什么

抓取范围仅限学校、学院、教育部研招网等**已公开网页**：目录、参考书目、通知、复试细则。

不抓、不转载：任何商业机构的真题打包、付费笔记、盗版 PDF。真题如需练习，通过学校档案馆、图书馆或学院当年是否公布的渠道获取。
