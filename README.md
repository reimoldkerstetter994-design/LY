# LY Dynamic Wallpapers

五张更露服装的动态壁纸。每张人物都有 5 个姿势关键帧，按动作时间轴交叉播放（回望、转身、踏步、举臂、坐起等），不是只靠雨和花瓣特效。

## 预览

```bash
./start-wallpaper.sh
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)

- 人物按编排做一套动作，循环播放
- `P` 或右上角按钮：横版 / 竖版
- `1`–`5` 或底部缩略图切换场景
- 空格轮播，`F` 全屏
- 右上角显示实时 FPS；掉帧会自动降画质

桌面上看竖版时，画面会收成手机比例的 9:16 画框。
