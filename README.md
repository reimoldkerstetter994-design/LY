# 夜巡 · 废弃医院(Night Watch)

一个可以直接在浏览器里游玩的第一人称 3D 恐怖游戏。纯前端实现,零构建、零外部资源:
3D 场景基于 Three.js,所有贴图由 Canvas 程序化生成,所有音效由 Web Audio 实时合成。

## 剧情

1998 年,圣玛丽亚疗养院在一夜之间被废弃。你是一名夜巡保安,接到报警后独自进入了这栋大楼——
大门在你身后锁上了。找齐 **6 根保险丝**,给出口大门恢复供电,然后活着离开。

但这栋楼里,不止你一个"人"。

## 怎么玩

### 在线运行

任意静态服务器即可(因为使用了 ES Module,不能直接双击打开 html):

```bash
# 任选其一
python3 -m http.server 8000
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

### 操作

| 按键 | 作用 |
| --- | --- |
| `W A S D` | 移动 |
| 鼠标 | 视角 |
| `Shift` | 奔跑(消耗体力,脚步声会引来"它") |
| `F` | 手电开关(耗电,可捡电池补充) |
| `E` | 拾取 / 互动 |
| `Esc` | 暂停 |

### 生存提示

- **手电照住"它"可以让它大幅减速**,但电量有限,要省着用。
- 它靠**视觉和听觉**找你:奔跑的脚步声能在很远处被听到,蹲在原地不动最安静。
- 心跳声和画面噪点越强,说明它离你越近——**别回头,跑。**
- 每收集一根保险丝,它都会变得更快、更暴躁。
- 出口大门上方有绿色"出口"灯牌,提前记住路线。

## 技术要点

- **Three.js r160**(已随仓库自带,可离线运行),`InstancedMesh` 渲染迷宫墙体,聚光灯 + PCF 软阴影手电。
- **程序化贴图**:发霉墙面、破旧地砖、血迹、血书、鬼脸、jumpscare 均由 Canvas 2D 实时绘制。
- **程序化音效**:环境低鸣、风声、心跳、耳语、吱呀声、突发刺响、jumpscare 尖啸全部由 Web Audio 合成。
- **迷宫生成**:递归回溯迷宫 + 随机开环 + 房间挖空,每局布局都不同;保险丝藏在死胡同。
- **鬼魂 AI**:BFS 寻路,游荡/追猎双状态机,基于网格 DDA 的视线检测,听觉半径随玩家动作变化,
  攻击性随收集进度提升,还会在剧本事件中闪现到玩家附近。
- 画面特效:动态噪点覆盖层(随鬼距离增强)、暗角、手电闪烁、灯光熄灭事件、镜头呼吸与步行晃动。

## 内容警告

包含突发惊吓(jumpscare)、恐怖音效与血迹元素,心脏不适者与儿童慎入。建议佩戴耳机、关灯游玩。
