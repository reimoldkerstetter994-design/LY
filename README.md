# 深渊回廊 (Abyss Corridor)

超真实3D恐怖游戏 — 在废弃精神病院中求生，躲避影魔的追捕。

## 游戏特色

- **超真实3D画面** — Three.js 渲染，PBR材质，动态阴影，后处理效果（暗角、色差、胶片颗粒、泛光）
- **动态恐怖AI** — 影魔会巡逻、追踪、传送，根据你的行为调整感知范围
- **沉浸式音效** — 程序化生成的环境音、心跳、低语、惊吓音效（无需外部音频文件）
- **恐怖氛围** — 闪烁灯光、随机停电、墙上血字、远处尖叫、跳跃惊吓
- **生存机制** — 手电筒电量、理智值、钥匙收集、蹲伏躲藏

## 快速开始

```bash
npm start
```

然后在浏览器中打开 http://localhost:3000

或直接双击 `index.html`（需要支持 ES Module 的现代浏览器）。

## 操作说明

| 按键 | 功能 |
|------|------|
| W/A/S/D | 移动 |
| 鼠标 | 环顾四周 |
| Shift | 奔跑（会发出更大声音） |
| F | 开关手电筒 |
| E | 拾取钥匙 / 开门 |
| Ctrl | 蹲下躲藏（降低被发现的概率） |

## 游戏目标

在废弃精神病院中找到 **3把钥匙**，打开出口大门逃离。小心 — 黑暗中有什么东西在看着你...

## 技术栈

- [Three.js](https://threejs.org/) — 3D 渲染引擎
- Web Audio API — 程序化恐怖音效
- 原生 ES Modules — 无需构建工具

## 注意事项

⚠ 本游戏包含惊吓画面、闪烁灯光和恐怖音效，建议佩戴耳机体验。
