# NIGHTFALL

A **Wallpaper Engine** web wallpaper pack: five 4K-ready 二次元 night scenes, landscape + portrait, mature / sexy outfits, rain · sakura · fireworks · sea spray · bedroom glow.

This is built as a **real Workshop product**, not a slideshow of AI poses and not a morphing video. Each scene is one finished illustration. Motion comes from atmospheric FX, light, and mouse parallax — the same category as the wallpapers that actually get listed and subscribed.

## Run on this PC

```bash

# http://127.0.0.1:4173
# http://127.0.0.1:4173/?we=1     Workshop / production look
```

- `1`–`5` scene · `P` portrait · `F` fullscreen · mouse for parallax
- In Wallpaper Engine the picker is hidden; change scenes from **Properties**

## Install in Wallpaper Engine

1. Wallpaper Engine → **Open in Editor**
2. **File → Load** the `wallpaper` folder (or unzip `dist/NIGHTFALL-workshop.zip`)
3. Confirm `project.json` type is **Web**
4. Preview, then **File → Export** / **Publish** to Workshop
5. Rating: **Mature** · Tags: `Anime`, `Girl`, `4K`, `Rain`, `Sakura`, `Night`, `Wallpaper Engine`

Listing copy: [STORE.md](STORE.md)

Pack for upload:

```bash
./pack-workshop.sh
```

## Why this can be listed

Wallpaper Engine Workshop already has thousands of successful **web wallpapers** that are a still plus rain/petals/fireflies. Users subscribe because the **art** is good and the **loop never stutters**. Pose-morph videos and five-keyframe splices do not pass that bar — they look like broken animation. NIGHTFALL ships the format that does.
