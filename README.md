# 南农土肥学硕雷达

实时抓取并汇总 **南京农业大学农业资源与环境学术型硕士**（当前按二级学科招生：`090301 土壤学`、`090302 植物营养学`）的官方公开资料。

本工具只索引学校研究生招生网、2026 硕士招生目录系统、资环学院官网的公开页面，**不抓取培训机构付费真题、网盘或讲义**。真题与版权复习资料请通过学校正式渠道或合法出版物获取。

## 抓取范围

| 来源 | 内容 |
| --- | --- |
| [南农研招网](https://zsgz.njau.edu.cn) | 招生章程、通知、复试办法、官方附件链接 |
| [招生目录系统](https://yzglxt.njau.edu.cn/gts2026/zsmlgl/zsml_ss_default.aspx) | 拟招生人数、研究方向、初试/复试科目、参考书目 |
| [资环学院](https://re.njau.edu.cn) | 学科介绍、学院新闻、土壤学系/植物营养学系导师名录 |

## 本地运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app crawl    # 立即抓取并打印 Markdown 快照
python -m app serve    # 打开 http://127.0.0.1:8000
```

浏览器打开后会自动执行一次抓取；也可随时点击「立即抓取最新公开页」。`/api/export.md` 可导出当前快照。

## 测试

```bash
python -m pytest -q
```

## 使用边界

- 目录中的拟招生人数含推免，公开招考名额以当年实际计划为准。
- 政治、英语、数学（农）/化学（农）为全国统考，大纲以教育部公布为准。
- 导师是否招生以学院当年通知和教师主页为准。
