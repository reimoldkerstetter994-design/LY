# 空壳病房 · THE HOLLOW WARD

一个跑在浏览器里的 **3D 第一人称生存恐怖游戏**。整座病院——几何体、材质、怪物、音效——全部在运行时用代码生成，仓库里没有任何美术或音频素材文件。

> 1987 年冬，圣墨林精神病院 B 区在一夜之间人间蒸发。
> 你带着一支快没电的手电走进去。
> **它一直都在这里，只是在等你先出声。**

---

## 快速开始

```bash
npm install
npm run dev      # http://127.0.0.1:5173
```

生产构建：

```bash
npm run build
npm run preview  # http://127.0.0.1:4173
```

需要支持 WebGL2 的桌面浏览器 + 鼠标键盘。**强烈建议戴耳机**。

> ⚠️ 含突发惊吓、高频闪光与强烈低频音效。光敏性癫痫患者请勿游玩。

## 玩法

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| `Shift` | 奔跑（噪音最大，它听得见） |
| `Ctrl` | 蹲伏潜行（几乎无声） |
| `F` | 手电筒开关 |
| `R` | 更换电池 |
| `E` | 互动 / 拾取 / 躲进铁皮柜 |
| `Q` | 屏住呼吸（躲藏时降低被发现概率） |
| `Esc` | 暂停 |

**目标**：在病院里找齐 5 枚保险丝 → 回到配电盘合闸 → 从安全门逃出去。

合闸之后灯会亮，路会变清楚——**它也会看得见你**。

三条互相牵制的资源：

- **手电电量**：唯一的光源，也是把你暴露出去的信号灯。
- **体力**：奔跑会耗尽，耗尽后一段时间跑不动。
- **理智**：黑暗中持续下降，站在灯下回升。理智见底时画面开始扭曲，你会听见不存在的低语、看见不存在的东西。

## 它是怎么运作的

### 完全程序化，零素材

| 内容 | 生成方式 |
| --- | --- |
| 关卡布局 | 递归回溯迷宫 + 编织（消除死胡同）+ 挖出病房 / 卫生间 / 停尸间 / 库房 / 办公室 |
| 墙地天花 | 逐面手工拼接的合并几何体，顶点色里烘了一层廉价 AO |
| PBR 贴图 | 逐像素跑 value/worley 噪声，烘出 albedo + roughness，再用 Sobel 从高度图推法线（无缝平铺） |
| 道具 | 由基本体拼出病床、轮椅、输液架、储物柜、货架、油桶、水槽、马桶、隔帘、吊钩…… 合并后用 `InstancedMesh` 批量绘制 |
| 墙上血字 | Canvas 2D 手写字 + 程序化血滴，烘成带透明通道的贴花 |
| 怪物 | 代码搭出的骨架层级 + 纯手写程序化动画（没有骨骼蒙皮，没有动画文件） |
| 全部音效 | Web Audio 实时合成：脚步、心跳、呼吸、低语、金属撞击、门轴、尖叫、惊吓音墙、混响用程序化生成的脉冲响应 |

### 渲染

- ACES Filmic 色调映射 + 极浓的指数雾，可见度被压到十几米。
- **两灯手电**：一束带阴影的窄光芯 + 一圈无阴影的宽溢光，外加叠加混合的体积光锥（多层嵌套锥面，透明度按视线与表面的夹角算，所以边缘会化开而中心是实的）。
- **灯光池**：天花板上有几十个灯具，但只有 2–4 个真实 `SpotLight`，每 0.2 秒重新分配给离玩家最近的那几个。每个灯具有自己的镇流器"性格"（闪烁频率、深度、掉电概率）。
- **后处理链**：`RenderPass → [GTAO] → UnrealBloom → OutputPass → HorrorGrade → [SMAA]`。
  `HorrorGrade` 是一个自写 Pass，一次搞定桶形畸变、色散、随理智值扭动的 UV 波动、幻觉撕裂、胶片颗粒、心跳脉冲缩放、受击红晕和冷调分级。

### 怪物 AI

- 网格 A\*（带二叉堆），每 0.32 秒重算追击路径。
- **听觉与视觉分开**：声音穿墙（奔跑传得最远，蹲伏几乎无声），视觉需要通视 + 视锥 + 你确实被照亮（手电开着 = 灯塔）。
- 状态机：`巡逻 → 调查 → 搜索 → 检查柜子 → 追猎 → 攻击`，外加一个 **潜伏（stalk）** 状态：它会瞬移到走廊尽头一动不动地站着，专门用来被你瞥见一眼；你盯久了它就消失，或者直接扑上来。
- 你躲进柜子时它会走到柜门外站着呼吸几秒，然后决定拉开门或者走掉。
- 合闸供电后它会进入激怒状态，标准 / 噩梦难度还会再来一只。

### 惊吓导演

恐怖最怕的是持续。`Director` 记录"你被放着不管了多久"，把这段安静换算成预算，再从一份代价递增的菜单里挑一件事做——远处的金属坠地、耳边的低语、整层灯同时熄灭、走廊尽头的人影、有人替你把头扭过去、最后是离你两步远的一张脸（此时手电会被自动压暗，好让你真的看清它）。

理智越低，菜单里越靠后的选项越可能被抽中。

## 目录结构

```
index.html              菜单 / HUD / 设置 / 死亡与逃脱画面
src/
  main.js               入口，串起所有界面与流程
  game.js               渲染器、世界装配、主循环、胜负流程
  core/
    utils.js            数学、种子随机、弹簧、噪声、事件总线
    settings.js         画质 / 难度预设与本地存档
    input.js            键盘 + 指针锁定
    audio.js            程序化音频引擎
  gfx/
    textures.js         PBR 贴图烘制 + 血字涂鸦
    materials.js        材质库、体积光锥、灰尘
    postfx.js           后处理链与 HorrorGrade
  world/
    maze.js             迷宫生成、BFS 距离场、通视、A*
    geometry.js         关卡外壳合并几何体（含顶点 AO）
    props.js            程序化道具库
    level.js            关卡装配：实例化、灯光池、目标物、装饰
  entities/
    player.js           移动、碰撞、手电、躲藏、镜头动态
    monster.js          骨架、程序化动画、感知、状态机
  systems/
    director.js         理智值、紧张度、惊吓调度
  ui/hud.js             HUD 与叠层
tools/                  无头浏览器测试脚本（见下）
```

## 开发用的无头测试脚本

三个脚本都用系统的 Chrome（SwiftShader 软件渲染）跑构建产物，截图落在 `tools/` 下对应目录：

```bash
npm run preview &                # 需要先起服务

node tools/smoke.mjs             # 走完整流程：菜单 → 建关 → 游玩 → 惊吓 → 躲藏 → 供电 → 逃脱
node tools/gallery.mjs           # 把镜头摆到十几个特定位置，用来审查画面
node tools/creature.mjs          # 单独检查怪物：量脚有没有踩在地上，各姿态出图
```

`smoke.mjs` 会在有任何控制台报错时以非零码退出，可以直接当 CI 用。
注意：软件渲染下帧率只有个位数，这是 SwiftShader 的填充率限制，不代表真实显卡上的表现。

## 画质档位

设置里三档，主要影响像素比、阴影图尺寸、投影灯数量、贴图分辨率、体积光层数、道具密度，以及是否启用 GTAO 环境光遮蔽与 SMAA。「极致」档才开 GTAO。
