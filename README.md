# 黑潮 · BLACKTIDE

台风夜。废弃海滨旅馆。第一人称 3D 动态恐怖。

戴耳机，关灯，点开 `index.html` 或任意静态服务器。

## 玩法

你接到妹妹最后一条短信：「别来。水已经进到墙里了。」你还是来了。黑潮旅馆的潮位表停在 3:13。

- 找到四份旅客记录
- 取到办公室钥匙 → 201 钥匙 → 锅炉钥匙 → 小艇钥匙
- 从进水的地下室码头逃走
- **潮客**会循着手电和奔跑的声音猎杀你。蹲下、关灯、躲进柜子。

## 操作

| 键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 鼠标 | 视角（点击画面锁定） |
| Shift | 奔跑（它听得见） |
| Ctrl | 蹲下 |
| F | 手电 |
| E | 开门 / 拾取 / 阅读 / 躲藏 |
| Esc | 暂停 |

## 本地运行

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

无需构建。Three.js 已放在 `vendor/three.min.js`。

## 技术

- Three.js r160，ACES 色调映射，软阴影，指数雾
- 程序化材质、动态暴雨、闪电、闪烁灯光
- Web Audio 程序化雨声 / 低频 / 心跳 / 雷
- 体力、电量、神智；神智归零即死
