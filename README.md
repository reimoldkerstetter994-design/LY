# 五十国之美 · 女性肖像相册集

跨文化摄影企划的数字相册：共 **50 册**，每册对应一个国家的**视觉文化灵感**（非真实人物身份档案），并标注 **五种美感层次**。

## 美感层次

| 层次 | 名称 | 含义 |
|------|------|------|
| L1 | 素真 | 肌理与呼吸，近乎无妆的纪实感 |
| L2 | 日常 | 街头与自然光里的生活美学 |
| L3 | 叙形 | 时装、建筑与文化符号的编织 |
| L4 | 典仪 | 仪式感、织物与历史质感的升华 |
| L5 | 诗境 | 超现实光影与梦境式构图 |

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址，可筛选层次/区域、搜索标签，点击卡片进入全屏画册视图（方向键或按钮切换册页）。

## 数据与影像

- 册页元数据：`src/data/album.ts`（标题、国别、区域、层次、标签、色板、摄影师手记）
- 封面图为在线占位图（Picsum），便于演示排版；正式拍摄可替换 `imageUrl` 为自有素材路径

## 说明

本仓库内容为**艺术摄影概念设计**，供排版、策展与教学参考。国别指创作灵感来源，不应被理解为对画中人物国籍或族裔的认定。
