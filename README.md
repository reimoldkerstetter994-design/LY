# 夜窗

二次元成人女性动态壁纸。打开 `wallpaper/index.html` 即可全屏播放。

人物按成年女性绘制：夜窗、蕾丝与晚礼服两个场景。画面会缓慢推近、左右漂移，并叠花瓣、窗光和光尘。蕾丝场景在三帧之间慢慢溶化。

## 播放

用浏览器打开 `wallpaper/index.html`，双击画面或按 `F` 进入全屏。

纯壁纸、不显示按钮：打开 `wallpaper/index.html?clean=1`，或在页面里按 `H`。

| 操作 | 作用 |
| --- | --- |
| 双击 / `F` | 全屏 |
| 鼠标移动 | 镜头轻微跟随，并唤出控制条 |
| 空格 | 定格或继续镜头与换幕 |
| `←` `→` | 上一幕 / 下一幕 |
| `1` / `2` | 蕾丝夜窗 / 晚礼服 |
| `P` | 花瓣开关 |
| `H` | 隐藏全部界面 |

Lively Wallpaper 选择「本地网页」，指向 `wallpaper/index.html`。Wallpaper Engine 同样可以用这个网页壁纸。

画面为 1280×720，铺满屏幕时会放大，大尺寸显示器上会略软。
