# 太阳系行星模拟

在浏览器里直接打开的交互式三维太阳系。无需安装、无需构建，用静态页面即可运行。

## 打开方式

1. 把仓库下载到本地
2. 用浏览器打开根目录的 `index.html`

也可以在仓库目录启动一个本地静态服务：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

首次加载需要联网，以获取 Three.js 与字体。

## 操作

- 拖拽：旋转视角
- 滚轮：缩放
- 点击行星或左侧列表：查看资料并跟随
- 空格：暂停 / 继续
- 数字键 `0`–`8`：聚焦太阳到海王星
- 底部面板：调节时间流速，开关轨道、名称、小行星带和卫星

## 说明

为了在同一画面里同时看到内行星和外行星，轨道半径做了视觉压缩；行星大小也不是真实比例。公转周期、偏心率、轴倾角和自转方向尽量按真实数据演示，例如金星逆向自转、天王星接近侧躺。
