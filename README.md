# 南农农业资源与环境学硕考研资料台

实时抓取南京农业大学**官方公开**的硕士研究生招生信息，专门整理一级学科 **农业资源与环境（0903）** 下的学术型硕士：

- `090301` 土壤学
- `090302` 植物营养学

并附原创 857 复习地图、公共课安排、复试规则解读。不收录商业真题包或盗版教材。

## 快速开始

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
python -m njau_are scrape --year 2026
python -m njau_are serve --host 127.0.0.1 --port 8765
```

浏览器打开 http://127.0.0.1:8765 ，可阅读本地快照；点「立即抓取官方最新」会再次访问：

- [南农研招网](https://zsgz.njau.edu.cn)
- [硕士招生目录查询系统](https://yzglxt.njau.edu.cn/gts2026/zsmlgl/zsml_ss_default.aspx)
- [资源与环境科学学院](https://re.njau.edu.cn)

## 2026 年官方要点（抓取结果）

| 专业 | 拟招 | 初试 | 复试 |
| --- | ---: | --- | --- |
| 土壤学 090301 | 21 | 101 / 201 / **314 数学（农）** / **857** | 0301 或 0305 |
| 植物营养学 090302 | 57 | 101 / 201 / **315 化学（农）** / **857** | 0307 植物营养学 |

857 官方书目：徐建明《土壤学》第四版；鞠美庭《环境学基础》；沈萍、陈向东《微生物学》第 8 版；武维华《植物生理学》第三版。

学院 2026 复试线（含推免计划口径）：土壤学总分 273、外语 45；植物营养学总分 275、外语 45。农学国家 A 线同年为 240 / 33 / 50。目标分请按学院线准备。

2027 年正式目录学校预告于 **2026 年 9 月**公布。已发布的预通知附件**未调整**资环学院 857 及相关学硕科目，在正式目录出台前按 2026 年准备，并用本工具复查。
