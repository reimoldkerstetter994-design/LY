# 视界

一台可观测宇宙的交互仪器。左边是实测近邻宇宙，右边是同一套时钟下的结构形成，底部时间轴从热大爆炸走到今天。

```bash
npm install
npm run dev
```

打开终端里打印的本地地址。`npm test` 核对背景演化和坐标，`npm run build` 产出静态页面。

## 画面里有什么

**观测图**把天体放在超银共动坐标里，原点是太阳。大约 40 Mpc 以内用红移无关的距离；更远的哈勃流天体用红移，会跟着 H₀ 变。拉尼亚凯亚、沙普利、英仙–双鱼等流域中心来自 Cosmicflows-4，坐标以 Mpc/h 存放，再除以 h。长城的折线只标出距离层，不是巡天骨架。

粒子视界、哈勃球和复合光子壳的半径来自同一条积分。复合之前没有微波背景壳，星系标记也会隐去。点「可观测宇宙」时，视野跟着**这一刻**的粒子视界，而不是今天的视界。

**结构形成**是 256 Mpc/h、32³ 的周期盒。初始条件是 BBKS 传递函数的高斯随机场，位移是泽尔多维奇近似，振幅按 σ₈ 归一。它不是对本超星系团的重构，也不是完整 N 体。纤维只连接高密度脊上最强的一条邻边。显示对比为 1 时位移就是这个归一；大于 1 只是把同一张初始图推得更深。

## 背景模型

平坦 ΛCDM 的弗里德曼方程，在对数尺度因子上积分：

H²(a) = H₀² [Ωₘ a⁻³ + Ωᵣ a⁻⁴ + Ωₖ a⁻² + Ω_Λ]

默认锚在 Planck 2018：H₀ = 67.36，Ωₘ = 0.3153，Ωᵦ = 0.0493。辐射密度取物质–辐射相等在 z ≈ 3402。增长因子 D(a) = H(a) ∫ da′ / (a′ H)³，并归一到 D(1) = 1。

温度按 T = T₀ / a 外推。在正负电子湮灭之前，这只是一条方便的标尺，不是完整的热历史。

预设里还有 SH0ES（H₀ = 73.04）和爱因斯坦–德西特。Ωₘ 滑到 1 时宇宙变平直物质主导，年龄约是哈勃时间的三分之二。

## 操作

拖拽旋转，滚轮缩放，点击光点。空格播放，左右方向键移动时间，方括号跳到相邻时代，`1` / `2` 切换观测图和结构形成，`f` 飞到当前天体。窄屏用顶栏的「天体」和「读数」打开侧栏。
