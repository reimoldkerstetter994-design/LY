# Moonlit Silver

4K 动态二次元壁纸：月光卧室、银发角色、花瓣与尘埃粒子、窗帘摇曳、镜头缓推和鼠标视差。

## 本地预览

```bash
./start-wallpaper.sh
```

浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)

- 双击或按 `F` 进入全屏
- 移动鼠标产生轻微视差

## Wallpaper Engine

把 `wallpaper/` 目录作为 Web 壁纸导入：入口是 `index.html`，预览图是 `assets/preview.jpg`。

分辨率素材为 3840×2160，页面会按屏幕等比铺满。
