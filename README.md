# 寂宅 · STILLHOUSE

一款可在浏览器里直接游玩的**第一人称心理恐怖游戏**。雨夜回家，钟停在 3:07。手电会吸引它。

## 在线游玩

用任意静态服务器打开项目根目录，例如：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

也可以把本仓库发布到 GitHub Pages，打开站点首页即可玩。

建议：**桌面端 + 耳机 + 全屏**。含突然惊吓、闪烁灯光与心理压迫。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D | 移动 |
| 鼠标 | 视角（点击画面锁定） |
| Shift | 奔跑 |
| Ctrl / C | 蹲下 |
| F | 手电 |
| E | 交互 / 躲进衣柜 |
| Esc | 暂停 |

## 目标

1. 在林宅里找到 **四盘录音带**
2. 在主卧取得育儿室钥匙，在育儿室取得地下室钥匙
3. 下到地下室，烧掉那本相册
4. 从正门逃进雨里

手电会暴露你。奔跑有脚步声。衣柜可以躲藏。神智掉光，或被它抓住，都会结束。

## 技术

纯前端，无需构建：Three.js（已内置 `vendor/three.min.js`）、程序纹理、Web Audio 程序音效。
