# 深渊回廊 (Abyss Corridor)

第一人称 3D 恐怖游戏：在四张地图、三种玩法中求生，躲避多种怪物。

## 运行

```bash
npm install
npm start
```

打开 http://localhost:3000 ，建议佩戴耳机。

## 玩法

| 模式 | 目标 |
|------|------|
| **逃离** | 收集全部钥匙，打开出口大门 |
| **生存** | 在倒计时结束前活下来，怪物会一波波醒来 |
| **猎杀** | 每拿一件遗物就会再唤醒一只怪物，拿齐后逃出 |

## 地图

- 废弃医院
- 废弃学校
- 地下墓穴
- 荒废庄园

## 怪物

- **影魔**：巡逻、追击、传送
- **爬行者**：低矮、更快
- **低语者**：远处近乎隐形，靠近时侵蚀理智
- **注视者**：你盯着它时它不冲，你一回头它就来

## 操作

| 按键 | 功能 |
|------|------|
| W/A/S/D | 移动 |
| 鼠标 | 环顾 |
| Shift | 奔跑（耗体力，更容易被发现） |
| F | 手电筒 |
| E | 拾取钥匙 / 电池 / 纸条，开门，躲进柜子 |
| Ctrl | 蹲下（降低被发现概率） |

柜子可以躲藏。电池补充手电。纸条会透露一点这个地方的事。

## 性能

地图用实例化墙体 + 网格碰撞，关闭实时阴影与后处理链，避免每帧重建包围盒。
