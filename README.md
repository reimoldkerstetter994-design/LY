# 南农大 · 农业资源与环境学硕考研资料抓取器

自动抓取并汇总 **南京农业大学** **农业资源与环境（学硕）** 考研相关公开资料，整合官方招生目录、参考书目、通知公告与复试附件，生成结构化 JSON 与 Markdown 报告。

## 功能特点

- 从研究生院**官方招生目录系统**抓取资环学院学硕专业信息（090301 土壤学、090302 植物营养学）
- 自动获取初试/复试科目**参考书目**（857、314、315、0301、0305、0307 等）
- 抓取研招网**最新通知公告**（招生章程、复试办法、专业目录等）
- 下载资环学院**复试细则 PDF** 等附件
- 抓取学院官网学科介绍页面
- 生成 `考研资料汇总.md` 与 `kaoyan_data.json`

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 执行抓取（默认输出到 output/ 目录）
python main.py scrape

# 显示详细日志
python main.py scrape -v

# 指定输出目录，不下载附件
python main.py scrape -o ./my_output --no-download
```

## 输出文件

```
output/
├── 考研资料汇总.md          # 人类可读的完整资料报告
├── kaoyan_data.json         # 结构化原始数据
└── attachments/             # 下载的 PDF/XLS 等附件
    └── 003资源与环境科学学院2026年复试细则.pdf
```
