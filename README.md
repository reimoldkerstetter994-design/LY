# 第十三病房 · WARD 13

一款可在浏览器里直接游玩的第一人称心理恐怖游戏。无需安装，打开页面即可进入废弃医院。

你在值班室醒来。表停在 2:17。走廊里有人拖着步子。灯，不该亮着。

## 如何游玩

用本地静态服务器打开（部分浏览器在 `file://` 下无法锁定鼠标）：

```bash
python3 -m http.server 8080
```

然后访问 [http://localhost:8080](http://localhost:8080)。

也可以把本仓库部署到 GitHub Pages、Netlify 或任意静态托管，即可在线游玩。

## 操作

| 按键 | 作用 |
| --- | --- |
| W A S D | 移动 |
| 鼠标 | 视角 |
| Shift | 奔跑 |
| Ctrl / C | 蹲下 |
| F | 开关手电 |
| E | 交互（开门、拾取、阅读、躲藏、逃出） |
| Esc | 暂停 |

## 目标

1. 在病房、护理部、手术室和太平间找到 **四张权限卡**。
2. 手电会暴露你的位置，也会慢慢耗电；黑暗会侵蚀神智。
3. 听见脚步时可以躲进储物柜，但被看见再躲就来不及了。
4. 集齐权限卡后，从一楼大门离开。

建议佩戴耳机。游戏包含突然的惊吓与闪烁灯光。

## 技术

纯前端：HTML / CSS / JavaScript，[Three.js](https://threejs.org/) 负责 3D 渲染。贴图与音效均在浏览器内程序化生成，不依赖额外资源文件。
