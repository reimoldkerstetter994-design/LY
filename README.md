# 南农农业资源与环境学硕考研资料台

实时抓取南京农业大学 **农业资源与环境** 学术型硕士（土壤学 090301、植物营养学 090302）的公开招生资料，做成可检索的资料台。

只采集学校研招网、学院官网、招生目录系统和中国研招网等 **公开网页**。不登录、不绕过权限、不抓商业真题站，也不提供教材/试卷全文。

## 能抓到什么

- 最新可用年份的硕士招生目录（拟招人数、研究方向、初试/复试科目）
- 857、314、315 及复试科目的官方参考书目页
- 研招网与资环学院通知（简章、复试、调剂、拟录取等）
- 土壤学系、植物营养学系公开导师名录与主页
- 学科介绍、农学门类国家线（A 类）对照

2027 年正式目录一般在当年 9 月发布。系统会自动探测 `gts2027`、`gts2026`…，没有新系统时展示最近一年，并保留预通知。

## 运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 立刻抓取并写入 data/cache.json
python -m nau_kaoyan scrape

# 打开资料台（默认 http://127.0.0.1:8000 ）
python -m nau_kaoyan serve
```

页面上的「立即抓取最新」会再次请求官网并刷新本地缓存。

```bash
python -m pytest
```
